# showcase/ — the money-shot

> **Purpose:** the part a reviewer actually sees in 90 seconds. A dashboard + screenshots that make the
> whole platform legible to a non-engineer. **Status:** planned (Phase 7). Spec only.

## Planned contents
- `dashboard/` — an **Evidence.dev** BI app on the Gold marts, answering 3–4 real questions:
  busiest stations & hours · net flow / rebalancing signal · availability (stock-out) over time ·
  ridership by member type. Deploys as a **static site to GitHub Pages** → a live link in the README.
- `media/` — screenshots + a demo GIF of the pipeline running, embedded in the top-level README.

## Why invest here
For a learn-and-showcase project, this layer *is* the product. A visible, clickable result is what
turns "interesting repo" into "let's talk." See [`../docs/CASE_STUDY.md`](../docs/CASE_STUDY.md).
